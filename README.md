### Hi, I'm Rafael 👋

Full Stack Software Engineer at [Medprev](https://github.com/Medprev), a Brazilian healthtech for booking medical appointments and exams. I work across the stack, from domain modeling and API contracts to the interface: Vue 3 and TypeScript on the front, NestJS, PostgreSQL and AWS on the back.

I practice **agentic engineering**: coding agents are part of how I build software, held to the same quality bar as any other code. I keep my own harness (context-scoped rules, versioned skills, and hooks that block a PR until review has run on the final diff) and orchestrate agents across product and engineering roles to ship backlog epics end to end.

Currently doing a postgraduate degree in **Software Engineering for Applied AI** at UNIPDS. Before code, I was an art director with a degree in design, which is why I care about interface details.
